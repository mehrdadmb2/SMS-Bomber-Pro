# 📱 SMS Bomber Pro

**ابزاری آموزشی برای تست امنیت و بررسی آسیب‌پذیری سرویس‌های ارسال OTP پیامکی (SMS) – نسخهٔ حرفه‌ای با رابط گرافیکی**

> **⚠️ هشدار حقوقی و اخلاقی**  
> این نرم‌افزار **فقط** برای اهداف آموزشی، تست نفوذ مجاز و ارزیابی امنیتی طراحی شده است.  
> استفاده از آن برای مزاحمت، ارسال پیامک انبوه ناخواسته، آزار دیگران یا هرگونه فعالیت غیرقانونی **اکیداً ممنوع** می‌باشد.  
> مسئولیت هرگونه سوءاستفاده کاملاً بر عهدهٔ کاربر است و توسعه‌دهنده هیچ مسئولیتی در قبال استفادهٔ نادرست نمی‌پذیرد.  
> **لطفاً فقط روی شمارهٔ خودتان یا با کسب اجازهٔ صریح از مالک شماره تست کنید.**

---

## ✨ ویژگی‌ها

- 🖥️ **رابط کاربری گرافیکی مدرن و راست‌چین** با `customtkinter` (تم تیره/روشن)
- 📊 **آمار لحظه‌ای** شامل تعداد کل درخواست‌ها، پیامک‌های موفق، خطاها، نرخ ارسال و درصد موفقیت
- ⚙️ **تنظیم نرخ ارسال** از ۱ تا ۲۰ درخواست در ثانیه (پیش‌فرض ۵ برای سازگاری با اینترنت ضعیف)
- 🎯 **قابلیت تعیین تعداد هدف**: توقف خودکار پس از رسیدن به تعداد مشخصی پیامک موفق
- 🔄 **بیش از ۱۰۰ سرویس ایرانی** برای ارسال OTP (نشان، دیجی‌کالا، دیوار، علی‌بابا، اسنپ، تپسی و...)
- 🌐 **پشتیبانی از پروکسی** (HTTP/HTTPS/SOCKS5)
- 🛠️ **ساخت فایل EXE مستقل** با یک کلیک – اجرا روی هر ویندوز بدون نیاز به پایتون
- 📝 **لاگ کامل** از شروع تا پایان عملیات با جزئیات خطاها

## 🚀 نصب و اجرا

### پیش‌نیازها
- پایتون ۳.۸ یا بالاتر
- کتابخانه‌های مورد نیاز به‌صورت خودکار در اولین اجرا نصب می‌شوند (`requests`, `customtkinter`).  
  در صورت استفاده از پروکسی SOCKS5، `PySocks` نیز به‌طور خودکار نصب خواهد شد.

### اجرای برنامه
۱. مخزن را کلون کنید یا فایل `sms_bomber_pro.py` را دانلود نمایید.
```bash
git clone https://github.com/YOUR_USERNAME/SMS-Bomber-Pro.git
cd SMS-Bomber-Pro
```
۲. برنامه را با پایتون اجرا کنید:
```bash
python sms_bomber_pro.py
```
۳. پنجرهٔ گرافیکی باز می‌شود.  
   - شمارهٔ موبایل مقصد را وارد کنید (حتماً با `09` شروع شود).  
   - در صورت نیاز پروکسی و نرخ ارسال را تنظیم کنید.  
   - (اختیاری) تعداد پیامک موفق هدف را مشخص کنید (اگر خالی بگذارید، تا بستن پنجره ادامه می‌یابد).  
   - روی **شروع ارسال** کلیک کنید.

## 🎨 شخصی‌سازی

### تغییر نرخ پیش‌فرض ارسال
- در کلاس `Engine` مقدار پیش‌فرض پارامتر `rate` را ویرایش کنید (خط ~۷۵۰):
```python
def __init__(self, phone: str, proxy: str = None, rate: float = 5.0, ...):
```
- در بخش GUI، اسلایدر و برچسب آن را به‌روز کنید (خط ~۹۲۰):
```python
self.rate_slider.set(5)
self.rate_label = ctk.CTkLabel(settings_frame, text="5 req/s", anchor="w")
```

### تغییر عنوان پنجره و هدر برنامه
- **عنوان پنجره** (نوار بالای برنامه):
```python
self.title("SMS Bomber Pro - نسخه آموزشی")
```
- **متن هدر** (بالای صفحه):
```python
self.header_label = ctk.CTkLabel(self, text="ارسال پیامک تستی (آموزشی)", ...)
```

### تغییر نام فایل EXE خروجی
- در متد `build_exe`:
```python
"--name", "SMS_Bomber_Pro"
```

## 🛠️ ساخت نسخهٔ EXE (ویندوز)

برنامه یک دکمهٔ **ساخت فایل EXE** دارد که با کلیک روی آن مراحل زیر انجام می‌شود:
- بررسی و نصب خودکار `PyInstaller` در صورت نیاز.
- بسته‌بندی تک‌فایلی و بدون کنسول.
- فایل خروجی در پوشهٔ `dist` ایجاد می‌شود و روی هر ویندوز بدون پایتون قابل اجراست.

همچنین می‌توانید دستی این کار را انجام دهید:
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name SMS_Bomber_Pro sms_bomber_pro.py
```

## ⚙️ نحوهٔ کار (فنی)

- **Token Bucket**: نرخ ارسال دقیقاً کنترل می‌شود تا از مسدود شدن IP جلوگیری کند.
- تمام درخواست‌ها یکباره در صف قرار می‌گیرند و سپس با رعایت نرخ مجاز اجرا می‌شوند.
- برای هر API تعداد مشخصی درخواست (`capacity`) ارسال می‌شود.
- پاسخ‌ها بررسی می‌شوند: کد وضعیت ۲xx و نبود کلید `error` یا `message` منفی به‌معنای موفقیت است.
- برنامه در صورت اینترنت ضعیف یا خطا، بدون کرش ادامه می‌دهد.
