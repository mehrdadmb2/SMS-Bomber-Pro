📘 Help / راهنما

🔧 Quick Start

Enter one or more phone numbers (09xxxxxxxxx) separated by commas or new lines. Upload a .txt file if needed. Set the sending rate (1-20 req/s), optionally a success target, and enable the Cloudflare Worker proxy. Click Start.

🧪 Test Button

Sends exactly 10 SMS requests to the first phone number in the list, using the current rate and proxy settings. Useful for verifying that everything works before a full run.

🔌 Test Worker

Checks if the Cloudflare Worker is online and responding correctly. If this fails, no SMS will be sent.

🌐 Proxy Setup

The tool uses a Cloudflare Worker to bypass CORS. Deploy the worker code (provided in the repository) and paste its URL here. Without a valid proxy, requests will be blocked by the browser.

⏰ Scheduler

Delay the start by entering seconds (e.g., 10 = start after 10 seconds).

🔐 Access Key

Append ?key=YOUR_SECRET to the URL to protect the tool. Without it, the tool will prompt for a key.

💾 Profiles

Save/load your configurations (phone list, rate, target, proxy) using the profile selector. Data is stored locally in your browser.

📊 Stats & Chart

Live statistics show total, success, failed, real-time rate, success percentage and ETA. The chart visualizes success vs failure over time.
